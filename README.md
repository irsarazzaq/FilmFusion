# 🎬 FilmFusion: Next-Generation Cinematic Telemetry & Interactive Streaming Portal

## 📌 Project Overview
**FilmFusion** is an advanced, enterprise-level ASP.NET Core MVC (Model-View-Controller) web application engineered for high-performance movie data streaming, real-time user interactivity, and dynamic system telemetry. 

This portal provides users with a highly responsive, modern UI/UX web platform while seamlessly integrating complex state management, session-driven persistent architectures, asynchronous AJAX processing engines, and an automated secure SMTP alerting pipeline operating natively in the background.

### 2. Multi-Tier Authentication & Automated Telemetry Pipeline

* **Session Persistence Engine:** Active state preservation across the entire dashboard matrix is securely bound using standard enterprise `HttpContext.Session` state containers rather than local client cookies.
* **Dual-Channel Automated SMTP Alerts:** Upon every successful login event, the backend authentication routine triggers an automated security alert dispatched natively to the user's mailbox over SSL via `smtp.gmail.com`.
* **Administrative Central Telemetry Logging:** Every diagnostic login trace is bundled as a real-time log payload and mirrored directly to the Global Admin Master node (`admin@filmfusion.com`) for comprehensive cluster monitoring.
* **Hardcoded Administrative Bypass Console:** Features a specialized administrative access routing node (`admin` / `admin123`) which bypasses standard controller blocks to grant operational oversight inside the secure `AdminConsole`.

### 3. Dynamic Asynchronous User Interaction Engine

* **AJAX Preference Updates:** Implements the `UpdateUserPreferences` operational endpoint to update persistent movie preferences instantly via intercepting jQuery/Fetch API JSON strings without generating page refreshes or postbacks.
* **Automated Robot Avatar Mapping Engine:** Establishes remote procedural pipelines linking with the external DiceBear Microservice API to generate dynamic robotic vector structures (`.svg`) dynamically scaled on individual profile username seeds.
* **Dynamic Watch History Tracker:** Tracks and binds instant runtime progressive tracking percentages directly linked with coordinated universal timestamps (`DateTime.UtcNow`) within the operational `WatchHistories` dataset tables.
* **Reactive Feedback Engine:** Connects custom asynchronous star feedback user controller parameters directly with mutable tracking context definitions to continuously output global star metric averages.
* **Raw SQL Structural Query Executions:** Maximizes pipeline execution response efficiency inside database layers by bypassing standard transaction loops with fast string-interpolated asynchronous native database queries (`ExecuteSqlRawAsync`) for both the Favorites and Watch Later subsystems.

1. Locate and launch the application's configuration script `appsettings.json` within your workspace directory.
2. Update the default connection properties string with your local SQL Server instance credential parameters.
3. Open the **Package Manager Console (PMC)** workspace inside Visual Studio (`Tools > NuGet Package Manager > Package Manager Console`).
